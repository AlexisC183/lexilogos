Note

Japanese kun readings (native) are written in lowercase; Chinese ON readings (borrowed) are written in uppercase.

How to use

For Kanji:

Type in the search field using Latin characters and select the desired Kanji from the list.

    Search filters:

  • Add an exclamation mark ! to limit the search to the exact characters typed; for example: a!
  • Add an equals sign = for a case-sensitive search; for example: a= for kun reading, and A= for ON reading.

For Kana:

Type directly in the main text area:

  • Hiragana: Use lowercase letters, for example: ka
  • Katakana: Use uppercase letters, for example: KA or Ka
  • Small Kana: Add = after a vowel; for example: a=, tsu= (or q)
  • Long vowels: Use a circumflex (â, Â) or, for Katakana, type an underscore _ after the vowel.
